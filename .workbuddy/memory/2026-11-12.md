
## Spotify Lyric Enhanced（LSPosed 模块）

- 基线：克隆 ivLis-Studio/ivLyrics-Android（commit a817377，v2.0.14）到本仓库，保留上游历史；
  功能分支 `feature/spotify-lyric-enhanced`，5 个提交，`main` 即上游基线。
- 功能 1（译词）：新增 PlatformLyricRow / ChineseLyricText / PlatformRecordingMatcher /
  PlatformTranslationAligner / PlatformHttpTransport / PlatformLyricSource / NeteaseLyricSource /
  QqLyricSource / PlatformTranslationSettings / PlatformTranslationService，接入 AiLyricsRepository
  的翻译任务（平台先填、缺行才走 AI）。
  - 可用端点：网易云 `api/search/get`（不能带 /web，会返回加密体）、`api/song/lyric`；
    QQ `client_search_cp`（不能带 new_json=1）+ `musicu.fcg` GetPlayLyricInfo（base64 的 lyric/trans）。
  - 版本否决要**双向**：查询或候选任一方带严格版本标签（live/remix/cover/...）且时长差 >5s 即否决。
- 功能 2（Genius）：GeniusClient 用 `api/search/multi` + `api/songs/{id}?text_format=plain` +
  `api/referents`，无需 token；AnnotationLineMapper 做 1–4 行窗口匹配；LyricsView 加虚线下划线与长按
  （hit target 必须带 LyricsLine，snapshot 拷贝也要带上）。
- 功能 3（歌词页）：LyricsPageSettings（边距 24dp 默认）、容器独占边距 + 渲染器 sidePaddingSp=0、
  PlayerBackgroundView.setStableSolidColor（300ms 交叉淡入）、底栏 PlayerProgressView + TransportButtonView
  接 NowPlayingService。
- 构建：需 JDK(Android Studio jbr) + SDK platform 36.1 + NDK 29.0.14206865 + cmake 3.31.6；
  `shared/tools/prepare_local_ai.py` 在 Windows 上要认 .exe（已修 cmake/ninja/llvm-strip）。
  产物 `spotify-module/build/outputs/apk/release/spotify-module-release.apk`（debug 签名）。
- 验证：`python tests/run_platform_translation_regression.py`（60 断言）、
  `python tests/run_platform_live_check.py`（真实网络）、`:shared:testDebugUnitTest`、
  `python tests/check_module_boundaries.py --built`（51 断言）。
- 阻塞：本机 GitHub 连接器无建仓权限（403），git 无凭据，PR 需用户建仓后推送；
  补丁已导出到 build/patches，说明在 build/PUSH.md。
